# Fight Camp – Box-Trainer-App

Persönliche Box-Trainer-App (Web-App/PWA) für zu Hause: 12 Anfänger-Lektionen mit Voice Coach, Fight-Camp-Plan, Essensplan, Tagesziele und Belohnungen.

- `index.html` – die fertige, offline-fähige App (React, CSS und App-Code eingebettet)
- `sw.js` – Service Worker für den Offline-Betrieb
- `manifest.webmanifest`, `apple-touch-icon.png`, `icons/` – Installation auf dem Homescreen
- `src/app.jsx` – Quellcode der App

Alle persönlichen Daten werden nur lokal auf dem Gerät gespeichert, nicht in diesem Repository.
